# Faliyev Prod — библиотека Фуада Алиева

Сайт сделан на основе вашего проекта (Книжная библиотека) — тот же текст, та же книга
«Изначальный код Вселенной», тот же тёплый редакторский стиль (кремовый фон, тёмно-синий
текст, тил-акцент). Технически переписан на обычный HTML/CSS/JS — без Vite/React,
чтобы его можно было запустить где угодно без сборки, и чтобы Railway разворачивал его
за секунды.

## Что изменено по вашему запросу

- **Лого**: слева вместо кружка «Ф» и подписи «Ф. Алиев / автор книг» теперь значок
  и надпись **Faliyev Prod**.
- **Вкладки** под шапкой: Книги, Аудиокниги, **Оплата**, Бесплатные тексты, Новинки,
  Популярное, Статьи.
  - «Книги» и «Популярное» ведут к разделу с книгой (она у нас пока одна).
  - «Оплата» открывает то же окно оплаты, что и в читалке.
  - «Аудиокниги», «Бесплатные тексты», «Новинки», «Статьи» — показывают блок
    «скоро…» с соответствующим текстом (для статей — «Скоро будут новые статьи»).
- **«Об авторе»** в верхнем меню плавно прокручивает страницу вниз и подсвечивает
  блок об авторе мягким затухающим свечением.
- Все остальные функции из вашего прежнего макета сохранены: страница чтения книги
  (`book.html`) с текстом, цитатой, комментариями, окно оплаты (демо), окно входа
  автора (демо), окно поиска (демо).

## Структура файлов

```
faliyev-prod-site/
├── server.js          — сервер для Railway
├── package.json
└── public/
    ├── index.html      — главная страница
    ├── book.html       — страница чтения книги
    ├── styles.css
    ├── app.js
    ├── favicon.svg
    └── assets/
        ├── cover.jpg   — обложка книги
        └── author.jpg  — фото автора
```

## Что редактировать под себя

- Тексты — прямо в `index.html` / `book.html`.
- Картинки — замените `public/assets/cover.jpg` и `public/assets/author.jpg` на новые
  файлы с теми же именами (или поменяйте путь в HTML).
- Реквизиты оплаты — окно оплаты сейчас демонстрационное (без реальных платежей).
  Когда решите, через что принимать деньги (ЮKassa, CloudPayments, Stripe и т.д.),
  на этом месте нужно будет подключить настоящую платёжную форму — напишите, помогу.

## Шаг 1. Загрузить сайт на GitHub

1. Зайдите на [github.com](https://github.com) → **New repository** → назовите,
   например, `faliyev-prod-site` → **Create repository** (ничего не отмечайте).
2. Распакуйте архив на компьютере.
3. На странице репозитория: **Add file → Upload files** → перетащите все файлы
   и папки из распакованного архива → **Commit changes**.

   Или через терминал, если установлен Git:
   ```bash
   cd faliyev-prod-site
   git init
   git add .
   git commit -m "Сайт Faliyev Prod"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/faliyev-prod-site.git
   git push -u origin main
   ```

## Шаг 2. Задеплоить на Railway

1. [railway.app](https://railway.app) → войдите через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите `faliyev-prod-site`.
3. Railway сам увидит `package.json`, выполнит `npm install` и запустит `npm start`.
4. Когда деплой завершится — зайдите в **Settings → Networking → Generate Domain**.
   Получите ссылку вида `faliyev-prod-site-production.up.railway.app` — это ваш
   рабочий сайт.

## Шаг 3. Обновления в будущем

Меняете файл на GitHub (можно прямо в браузере: открыть файл → карандаш ✏️ →
изменить → Commit changes) — Railway сам подхватит изменение и передеплоит сайт.

## Проверка на компьютере (по желанию)

```bash
cd faliyev-prod-site
npm install
npm start
```
Открыть `http://localhost:3000`.
